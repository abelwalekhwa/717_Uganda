This is a 7-1-7 Ugandan Project under Ministry of Health, Uganda. 
**The Tittle:** Deaths and Infections Averted: A Cost-Effectiveness Analysis and Factors that influence Adoption and Implementation of the 7-1-7 Targets in Uganda: A Case Study of Three Priority Diseases![image](https://github.com/user-attachments/assets/970712bc-5870-4490-9c9e-778570cb1ec4)
The Objectives are
a) To estimate the number of deaths and infections from priority diseases (EVD, anthrax and measles) averted if 7-1-7 targets are met in Uganda 
b) To conduct a cost-effectiveness analysis for implementing the 7-1-7 framework in responding to priority diseases (EVD, anthrax and measles) using a societal perspective
c) To explore and profile the factors that influence the adoption and implementation of 7-1-7 targets in Uganda
![image](https://github.com/user-attachments/assets/27bfe76b-75bb-4d08-a82a-a2debc46a9a1)

Adopt the Starsim Framework and Dominic's work (https://www.medrxiv.org/content/10.1101/2024.06.02.24308241v1.full)
